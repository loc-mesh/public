# public

- **Repo:** https://github.com/loc-mesh/public
- **Visibility:** **public** (the only public repo in the `loc-mesh` org)
- **Purpose:** Material intended for the general public — anything the project wants visible to the outside world. Contents and exact role are still being defined.
- **Status:** active, scaffolding stage.
- **Notes:**
  - World-readable. Never include credentials, internal-only context, vendor names under NDA, or unreleased plans.
  - When in doubt about whether something is shippable here, draft it in `design/` first and promote only after explicit user approval.
  - This is the **only** public repo in the org. All other repos default to private.
